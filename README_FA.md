# Watch Time — نسخه وب

## به‌روزرسانی گزینه‌های ثبت سریال

این نسخه دو گزینه سریع به جزئیات هر عنوان اضافه می‌کند:
- **قبلاً تماشا کردم**: برای فیلم، فیلم را دیده‌شده ثبت می‌کند؛ برای سریال، همه قسمت‌هایی را که اطلاعاتشان از TMDB دریافت شده دیده‌شده علامت می‌زند و زمان تماشا را حساب می‌کند.
- **می‌خواهم بعداً تماشا کنم**: عنوان را فقط به بخش «واچ‌لیست» می‌برد؛ در آمار زمان تماشا حساب نمی‌شود.

## به‌روزرسانی سایت روی GitHub Pages

1. فایل ZIP را روی کامپیوتر استخراج کن.
2. وارد مخزن GitHub خودت شو.
3. فایل `index.html` جدید را در ریشه مخزن بارگذاری کن و گزینه جایگزینی فایل قبلی را تأیید کن.
4. روی **Commit changes** بزن و چند دقیقه صبر کن تا GitHub Pages به‌روزرسانی شود.
5. سایت را باز کن. اگر نسخه قبلی را می‌بینی، یک بار صفحه را Refresh کن یا سایت را در Chrome ببند و دوباره باز کن.

اطلاعات کتابخانه در حافظه همان مرورگر ذخیره می‌شود؛ پیش از به‌روزرسانی بهتر است از تنظیمات برنامه «خروجی پشتیبان» بگیری.
