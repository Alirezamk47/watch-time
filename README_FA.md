# Watch Time — نسخه وب قابل نصب (PWA)

این پروژه یک وب‌اپ فارسی است که از طریق HTTPS قابل نصب روی صفحه اصلی گوشی است و به Android Studio نیاز ندارد.

## راه‌اندازی آسان با Netlify Drop
1. فایل ZIP را استخراج کن.
2. وارد https://app.netlify.com/drop شو و در صورت درخواست، وارد حساب کاربری شو یا حساب بساز.
3. پوشه `watchtime-pwa` را که فایل‌های `index.html`, `manifest.json`, `sw.js` و پوشه `icons` داخل آن است، در صفحه Drop بارگذاری کن. اگر سایت فقط ZIP را نپذیرفت، پوشه استخراج‌شده را انتخاب/رها کن.
4. پس از انتشار، Netlify یک آدرس HTTPS به شکل `https://....netlify.app` می‌دهد.
5. آن آدرس را در Chrome اندروید باز کن؛ از منوی سه‌نقطه گزینه «Install app» یا «افزودن به صفحه اصلی» را بزن.

## اتصال TMDB
1. در اپ، وارد «تنظیمات» شو.
2. API Read Access Token را که از TMDB گرفته‌ای وارد کن.
3. «ذخیره توکن» و بعد «تست اتصال» را بزن.
4. اگر اتصال موفق بود، به جستجو برو و نام فیلم/سریال را وارد کن.

## امکانات فعلی
- جستجوی چندگانه فیلم و سریال با TMDB
- نمایش پوستر، سال، امتیاز، خلاصه و مدت فیلم
- نمایش فصل‌ها و قسمت‌ها و علامت‌زدن قسمت‌های دیده‌شده
- محاسبه زمان تماشا از مدت فیلم/قسمت‌هایی که runtime دارند
- کتابخانه محلی و آمار پایه
- خروجی و بازیابی پشتیبان JSON
- ذخیره توکن و کتابخانه در مرورگر همان دستگاه
- پوسته PWA و فایل‌های آفلاین پایه

## رفع خطاهای اتصال
- این نسخه را با `file://` یا از پیش‌نمایش محلی باز نکن؛ باید از آدرس HTTPS منتشرشده اجرا شود.
- از API Read Access Token استفاده کن، نه کلید کوتاه API v3.
- اگر خطای اتصال می‌آید، اینترنت، VPN/فیلترشکن یا محدودیت شبکه را بررسی کن.
- توکن در مرورگر همین دستگاه ذخیره می‌شود؛ آن را در چت یا جای عمومی منتشر نکن.

## حریم خصوصی
اطلاعات کتابخانه و توکن در localStorage مرورگر ذخیره می‌شوند. پاک‌کردن داده‌های سایت ممکن است آن‌ها را حذف کند؛ پشتیبان بگیر.
